Chest keeps your files the way a shared drive does: in team spaces and in your
own **My files**, in folders as deep as you need. Nothing needs a type, an
owner or a reviewer before it goes in.

## Team spaces and folders

Open **Files** and create a team space; you become its manager. Add members
from the space's **Members** card as viewer, commenter, contributor, content
manager or manager. Every folder and
file in the space inherits those roles; a folder marked **Restricted** keeps
inherited members out, except managers.

In a space or folder, **New folder** adds one inside it. The breadcrumb above
each folder's name shows where you are. **Rename**, **Move** and **Move to
trash** sit below the contents; a moved folder takes everything inside it, and
a trashed one comes back from **My trash**.

## Upload files

Drop files anywhere on a folder page, or press **Choose files**. On a phone the
same place also offers **Take a photo**. Each file shows its progress as it goes
up. Large files go up in parts, up to 4 GB per file:

- if the connection drops, the upload waits and continues by itself;
- if you reload or close the page, the folder lists the upload under
  **Unfinished uploads**: choose or drop the same file again and it continues
  from the parts Chest already has;
- a file appears only once every byte has arrived and its SHA-256 fingerprint
  is recorded. **Cancel upload** discards the parts.

A file's page takes a new version the same way.

## Find a file

The search field on **Files** and on every space looks through file names and
the words inside files and scans, and shows a short extract around each match.
It only finds what you can open now. See
[Text inside files and scans](/docs/reading).

**Shared with me** lists what colleagues shared with you, newest first.

## Go back to an earlier version

Every version stays in the file's **Version history**. **Restore as current
version** on an earlier one makes a new version with the same bytes; the later
versions stay.

## Restore a folder to a date

On a folder (or, for a space's manager, the whole space) open **Restore to a
date**, choose the date and time as your own clock shows it, check the **Time
zone** (Chest fills in your computer's), and press **Preview restore**. A time
that has not happened yet is refused with a plain message. The preview
lists each file and folder that would change: an earlier version, its old name
or place, a deleted item brought back, and items added since, which go to
trash. Nothing changes until you press **Restore selected items**. Untick
anything you want to leave as it is.

The restore writes each change as a new state, so later versions are kept.
**Undo this restore** on the receipt, or **Undo** under **Recent restores** on
the folder, puts every item back as it was just before. Access removed since
the chosen date is never given back by a restore.

Contributors restore only the files they added. Managers restore everything in
the folder.
