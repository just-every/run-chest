Every file and folder page has its sharing on the side: colleagues and
groups, a link for your organization, a link for anyone, and on a folder, a
file request. **Links** under **Files** lists every link and request you made
or can manage.

## Share with colleagues and groups

Under **Share**, choose a **Person or group** and a **Role** (viewer,
commenter or editor), add an optional message and an optional date when the
access ends, and press **Share**. A shared folder shares everything inside it.
The person finds it under **Shared with me**.

**People with access** lists each share with **Remove access**, and
**Extend by 7 days** on one that expires. Someone without access can ask for
it; the request shows under **Access requests** with **Approve** and
**Decline**.

## A link for your organization

**Organization link** makes a link that anyone signed in to this Chest opens
at the link's role. Choose whether colleagues can find it in search. Opening
the link grants nothing lasting: revoking it ends that access.

## A link for anyone

**Link for anyone** opens the file, or the folder and its files, without an
account. Each link can have:

- a password,
- an expiry date,
- a download limit.

Chest shows the link once, when you make it; copy it then. Each link reads
like *Expires Nov 30 · 3 of 10 downloads*, with one **Revoke** button. The
next request through a revoked, expired or used-up link gets a plain page that
says so, never the file. Every open and download is in the file's activity.

**Make private** turns off every link on the file or folder in one click and
keeps the people and groups it is shared with.

## Ask anyone to upload: file requests

On a folder, **File request** makes a link that lets anyone upload into that
folder without an account. They cannot see what is already there. You can
give it a title, a message, the file types it accepts, the largest file size
and a deadline. **Close request** stops it.

## Shared too widely

**Links** starts with what may be shared too widely: links anyone can open,
links with no expiry or open for a long time, links past their expiry or
download limit, and organization links colleagues can find in search, each
with the reason and **Make private**.

## Organization link controls

An organization link can require a password, expiry and download limit, and select the current, pinned or approved original. A password admission belongs to the signed-in staff session for at most 12 hours; it never turns into a named grant. Removing or changing the link applies on the next request. People who already hold an independent named or group role retain those rights. Without those independent rights, viewer/commenter search, history, comments and activity follow the selected versions and cannot expose pending replacements. Editing requires current versions and original download permission.

Downloads charge the oldest applicable organization link first when several grants permit the same original. Each successful admission updates the count atomically. Range requests and retries each count once. The item and Links views show expiry and used downloads; Revoke needs one click. Pinned folder snapshots retain membership, paths, names and exact originals, up to 5,000 descendants and 100 levels; larger snapshots are refused explicitly. Later restrictions, moves out of the root, trash and revocation still apply.
